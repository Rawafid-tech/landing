# 🚚 Rawafid (روافد) – Project Spec

---

# 🇺🇸 English Version

## 1. Overview

Rawafid (روافد) is a logistics operating system for e-commerce businesses that centralizes shipping, returns, courier integrations, and delivery tracking into one unified platform.

The landing page is the main marketing entry point and must clearly communicate:
- Premium SaaS positioning
- Logistics infrastructure mindset
- Simplicity + operational power
- High conversion focus (trial + demo)

---

## 2. Tech Stack

- Astro (Primary Framework)
- TailwindCSS
- TypeScript
- Framer Motion / Motion One (animations)
- GSAP (advanced scroll animations)

### Why Astro?
- Fast performance
- SEO optimized
- Island architecture for interactive components
- Ideal for marketing landing pages
